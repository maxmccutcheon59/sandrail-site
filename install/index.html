1 · Install + demo

60-second path (v0.3.0)

bash
git clone https://github.com/maxmccutcheon59/sandrail.git
cd sandrail
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
sandrail demo
sandrail packs list
sandrail packs run ci_gate
